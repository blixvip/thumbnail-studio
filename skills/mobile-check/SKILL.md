---
name: mobile-check
description: Review a thumbnail at realistic small display sizes and prioritize legibility fixes.
---

Inspect the actual attached thumbnail. If no image is available, ask for it instead of issuing a pretend visual review. Assess the image at approximately 320 by 180 pixels and 160 by 90 pixels when the available tools permit real resizing. If they do not, state that the review is qualitative.

Check whether the main subject, essential object, and any text can be understood quickly. Identify lost facial expressions, thin lettering, small interface details, muddy silhouettes, distracting highlights, and important content in the lower-right overlay area. Consider grayscale and color-vision differences as additional hierarchy checks.

Return the three most important fixes in impact order, with concrete instructions such as increasing subject size, removing a background element, or reducing a headline to fewer words. Separate observed defects from predictions. Finish with a revision prompt that preserves the intended concept and changes only the diagnosed problems. Never claim a test was executed if you only described it.
