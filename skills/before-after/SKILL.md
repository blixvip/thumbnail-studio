---
name: before-after
description: Communicate a supported transformation with comparable framing and a clear visual contrast.
---

Determine what actually changed and which evidence the user has. Do not invent a before state, improvement metric, weight change, financial result, or other outcome. Ask for missing source images or label a concept as illustrative.

Use comparable viewpoints, scale, and lighting so the contrast is understandable and fair. Choose a simple split, progression, or foreground-background relationship. Make the transformation visible without depending on a long caption. Use short labels only if viewers cannot otherwise identify the two states.

Specify the split position, hero region, matched anchor points, color treatment, and optional directional cue. Avoid adding a dramatic expression or unrelated shock element that changes the video's claim. Provide a final image prompt or editing plan, followed by checks for honest representation, alignment, balanced emphasis, and readability when reduced. If only one source state is supplied, request the other rather than pretending both are available.
