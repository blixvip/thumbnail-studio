# Thumbnail Generator

A local image library for the thumbnail app. Imports portfolio images, preserves their source links, removes exact duplicates, and provides a searchable gallery with favorites and full-size downloads.

The library and importer work. ChatGPT integration, editing, and thumbnail generation are not implemented yet.

## Open the library

From this folder:

```powershell
python -m thumbnail_library serve
```

Open <http://127.0.0.1:4317>. The server binds only to this computer and exposes the gallery and imported media.

## Setup on another computer

Requires Python 3.11+, Node.js, and Google Chrome. Install the image decoder and browser tooling:

```powershell
python -m pip install -r requirements.txt
npm ci --ignore-scripts
```

If your Python installation uses uv instead of pip, use `uv pip install -r requirements.txt` in your environment.

## Import or refresh

```powershell
npm run capture
npm run import
```

Capture opens a separate, disposable headless Chrome, scrolls each configured page, and collects rendered images, including lazy-loaded images and CSS backgrounds loaded by the browser. Import downloads originals when exposed, creates gallery previews, records dimensions and provenance, and deduplicates identical file contents.

The importer uses saved captures when available. Run capture again before import to discover newly added images. To capture one source, use `node scripts/capture.mjs "Dava Studios"`.

Add more portfolio pages as `{"name": "Studio name", "url": "https://example.com/portfolio"}` entries in [sources.json](sources.json), then run both commands. Current sources:

- [Clickables](https://www.clickables.co/portfolio)
- [Dava Studios](https://davastudios.com/services/thumbnails)
- [Viewstack Labs](https://viewstacklabs.com/)
- [Matt Philie](https://www.mattphilie.com/thumbnails)
- [TKG](https://tkg.yt/)
- [Boostraft](https://boostraft.com/)
- [Kyani Visuals](https://www.kyanivisuals.com/)

## Local files

- `data/images/`: original downloaded raster files.
- `data/previews/`: smaller JPEG gallery previews.
- `data/manifest.json`: image metadata, source URLs, and per-source import reports.
- `data/captures/`: rendered page snapshots and browser-downloaded image cache.
- `artifacts/`: local UI verification screenshots.

Downloaded media and captures stay on your computer and are excluded from Git. They are imported third-party work, not output generated by this app. Original files are preserved unchanged. Favorites are stored in this browser's local storage.

## Import boundaries

The importer collects discoverable raster images on the configured pages. It does not log in, crawl every page of a domain, click gated galleries, or fetch private assets. Galleries behind extra pagination or category buttons may require adding their dedicated URLs. SVG icons, videos, tiny tracking images, invalid files, oversized images, and failed requests are skipped. Import reports retain failures; the gallery groups all photos separately from a dimensions-based thumbnail filter. A thumbnail classification does not imply a manually verified content category.

## Verification

```powershell
npm test
npm run verify-ui
npm audit
```

UI verification requires the local server running and at least one imported image. It checks 1440px, 390px, and 320px layouts, search, previews, favorites persistence, and empty/error states. Tests cover image extraction, URL restrictions, exact duplicate handling, corrupt files, and repairing missing imported files.
